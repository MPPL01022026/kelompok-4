## 👋 01. Selamat Datang di Repository Kami!

Halo semuanya! 👋

Selamat datang di repository resmi **Kelompok 4** dalam proyek pengembangan perangkat lunak.

Repository ini merupakan tempat kami berkolaborasi untuk merancang dan mengembangkan website bagi **UMKM Bakso Jambo Langsa, Aceh**.

Melalui proyek ini, kami ingin memperkenalkan usaha kuliner lokal melalui platform digital yang informatif, menarik, dan mudah diakses. Website ini dirancang untuk menampilkan informasi usaha, menu bakso, serta galeri foto produk yang dapat diperbarui secara online.

### 🎯 Tujuan Proyek

- Memperkenalkan UMKM Bakso Jambo Langsa kepada masyarakat melalui website.
- Menampilkan menu, harga, dan foto produk.
- Menyediakan galeri foto yang dapat dilihat oleh semua pengunjung.
- Memungkinkan pengelola mengunggah foto baru melalui penyimpanan online.
- Memudahkan pelanggan mendapatkan informasi usaha.
- Menerapkan proses pengembangan perangkat lunak secara kolaboratif menggunakan Git dan GitHub.
