## 👋 Selamat Datang di Repository Kelompok 4!

Halo semuanya! 👋

Selamat datang di repository resmi **Kelompok 4** dalam proyek pengembangan perangkat lunak.

Repository ini dibuat sebagai tempat kolaborasi kami dalam merancang dan mengembangkan website untuk **UMKM Bakso Jambo di Langsa, Aceh**.

Melalui proyek ini, kami ingin membantu memperkenalkan usaha kuliner lokal melalui website yang informatif, menarik, dan mudah diakses oleh masyarakat.

> 💡 *Small Business, Big Digital Impact!*

## 🎯 Tentang Proyek

**Nama Proyek:** Website UMKM Bakso Jambo Langsa

**Bidang:** Sistem Informasi dan Pengembangan Perangkat Lunak

**Tujuan Proyek:**
- Memperkenalkan UMKM Bakso Jambo kepada masyarakat melalui media digital.
- Menampilkan informasi usaha dan menu bakso.
- Menyediakan galeri foto produk yang menarik.
- Mengembangkan fitur unggah foto agar pengelola dapat memperbarui galeri secara online.
- Menerapkan metodologi Agile dalam proses pengembangan perangkat lunak.
- Membangun pengalaman kerja tim menggunakan Git dan GitHub.

## 📋 Dokumentasi Sprint 1

Dokumentasi pengembangan proyek tersedia pada folder `docs/`.

- 📌 **WBS:** pembagian pekerjaan dan ruang lingkup proyek.
- 🔄 **Agile Methodology:** penerapan metode Agile dan perencanaan Sprint 1.
- 📊 **Function Point Analysis:** estimasi ukuran fungsional sistem.
- 🎨 **UX Design:** rancangan pengalaman pengguna dan navigasi.
- ⚙️ **Project Setup:** panduan konfigurasi dan deployment.
- 📝 **Requirements:** kebutuhan fungsional dan nonfungsional.
- 🧪 **Testing:** rencana pengujian fitur website.

## 🤝 Kolaborasi Tim

Kami menggunakan GitHub untuk mengelola perubahan dan berkolaborasi.

1. Anggota membuat salinan repository atau branch sesuai kebutuhan.
2. Setiap anggota mengerjakan tugas yang telah disepakati.
3. Perubahan diuji sebelum diajukan.
4. Pull Request digunakan untuk meninjau perubahan.
5. Dokumentasi diperbarui seiring perkembangan proyek.

## 🎓 Tujuan Pembelajaran
