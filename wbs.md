# Work Breakdown Structure (WBS)
## Proyek: Website UMKM Bakso Jambo Langsa

### 1. Inisiasi dan perencanaan
1.1 Mengidentifikasi masalah dan tujuan website  
1.2 Mengumpulkan kebutuhan dari pemilik UMKM  
1.3 Menentukan ruang lingkup Sprint 1  
1.4 Menentukan peran anggota tim

### 2. Analisis kebutuhan
2.1 Menyusun kebutuhan fungsional  
2.2 Menyusun kebutuhan nonfungsional  
2.3 Memverifikasi data menu, harga, lokasi, jam buka, dan kontak  
2.4 Menentukan aturan unggah foto dan hak akses

### 3. Perancangan
3.1 Menyusun sitemap dan alur navigasi  
3.2 Membuat wireframe halaman utama  
3.3 Menentukan warna, tipografi, dan komponen responsif  
3.4 Merancang alur galeri foto dan autentikasi pengelola  
3.5 Merancang skema tabel dan kebijakan akses Supabase

### 4. Implementasi
4.1 Membuat struktur HTML  
4.2 Membuat stylesheet responsif  
4.3 Membuat navigasi dan interaksi JavaScript  
4.4 Menyiapkan proyek Supabase  
4.5 Membuat galeri baca-publik  
4.6 Membuat login pengelola dan unggah foto  
4.7 Menyiapkan GitHub Pages

### 5. Pengujian
5.1 Menguji tampilan desktop dan mobile  
5.2 Menguji navigasi dan aksesibilitas dasar  
5.3 Menguji unggah format foto yang diizinkan  
5.4 Menguji batas ukuran file  
5.5 Menguji akses publik dan pengelola  
5.6 Memeriksa pesan kesalahan dan dokumentasi

### 6. Rilis dan evaluasi
6.1 Review kode melalui Pull Request  
6.2 Memperbarui README dan dokumen Sprint  
6.3 Deploy versi demo  
6.4 Mengumpulkan umpan balik  
6.5 Menyusun backlog Sprint berikutnya

## Deliverable Sprint 1
- Repository template dan README
- Website awal responsif
- Dokumen WBS, Agile, Function Point, setup, UX, kebutuhan, dan testing
- Rencana integrasi Supabase dan daftar pengujian

## Catatan
Estimasi waktu, penanggung jawab, dan status tiap pekerjaan perlu diisi oleh kelompok berdasarkan anggota serta kalender perkuliahan.
